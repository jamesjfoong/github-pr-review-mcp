# Documentation Agent

**Purpose**: Maintains project documentation and ensures it stays up to date.

## Responsibilities

- Update README.md when adding new tools
- Update CHANGELOG.md for user-facing changes
- Keep code examples accurate
- Update CONTRIBUTING.md if workflow changes
- Maintain AI Code Editor Guide

## When to Use

When adding features, changing behavior, or improving documentation.

## Key Rules

- Update README.md tool table when adding tools
- Add CHANGELOG entries for user-facing changes
- Keep examples in sync with actual code
- Update documentation when architecture changes
- Use clear, concise language
- Include code examples where helpful

## Documentation Files

- `README.md` - Main project documentation
- `CHANGELOG.md` - Version history
- `CONTRIBUTING.md` - Contribution guidelines
- `docs/` - Additional documentation (deployment, security)
- `.cursor/rules/main.mdc` - Cursor rules documentation
